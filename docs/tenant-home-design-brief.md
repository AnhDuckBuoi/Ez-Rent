# Tenant home redesign — preview only

Scope: docs/tenant-home-outline.js, docs/tenant-home-outline.css; canvas/wrapper integration. Mode: Operate with a Read section. Code first, existing EZ Rent/P3 identity retained. This is not a new brand or a marketing landing page.

Confirmed brief: Vietnamese tenant homepage, notices and useful articles prominent; room browsing belongs to Search; at most two saved rooms. Existing navigation, article content, mock data semantics, exclusive two-hour hold and six-hour notice remain.

THESIS: A tenant opens Home to see what changed and what happens next, then can read or find a room without a wall of listings.

OWN-WORLD: Preserve the established blue, white surfaces and familiar sans typography of P3. Neutral #f6f7f9 ground, #1f2f40 text, #356797 actions. App clarity over ornament. No replacement visual-world workshop: current user has already settled page purpose, scope, device classes and content emphasis.

STORY: Greeting and Find room → next confirmed visit and recent notices → useful reading with an actual preparation checklist → compact saved items and help. Desktop has a quiet utility rail. Mobile uses one DOM reading order with next visit/notices before articles.

FIRST VIEWPORT: Greeting, Find room, date, confirmed visit with arrival time/address, two recent notices. The main focal point is actionable visit information. No decorative hero or synthetic scene.

FORM: 8px spacing rhythm, flat section dividers, one functional appointment panel, understated 12–16px panel corners, legible 14–16px copy. Article filters are tabs with text and a current underline; articles expand inline. No illustration assets, invented commercial news, metrics or loading theater. Keep accessible focus, reduced motion, meaningful empty states. Launcher failed on Windows; context and review performed directly, no claim of automated Impeccable gates.

FINISH: capture desktop/mobile/tablet, review core actions and empty states, document actual tokens, report preview scope and any remaining limitations.
